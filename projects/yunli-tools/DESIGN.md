# YunLi 面板设计规范

## 视觉来源

以 [DeepSeek 官网](https://www.deepseek.com/) 和 [DeepSeek Harness](https://www.deepseek.com/harness/) 为视觉来源。仓库级执行约束见根目录 `AGENTS.md`；修改设计时同步维护两份文档。
- 浅色：#f9f8f8 冷白底、#1e232c 正文、蓝色环境光、半透明白色表面、细边框和胶囊按钮。
- 深色参考 Harness 应用预览的炭灰阶：#151517 背景、#202126 面板、#191b21 输入区，弹层与选中项逐级提亮；蓝色环境光保持低强度。
- 深色正文与主操作使用柔和的 #e4e7ee，辅助文字 #a6adba。面板、控件、选中背景分别定义，不靠透明白叠加形成不稳定层次。
- 黑白主操作、品牌蓝链接和选中提示、圆润分区；不使用实色蓝色主按钮和方形后台式卡片。
- 文字优先可读性；输入框边界、正文、焦点对比度要单独验证。系统字体替代官网的远程字体。

### 对齐、节奏与字体依据

参考 [Fluent Layout](https://fluent2.microsoft.design/layout) 的接近性、对齐和间距阶梯，以及 [Fluent Typography](https://fluent2.microsoft.design/typography) 的语义排版和基线原则。Fluent 以 4px 为基础，并允许 2/6/10px 等光学校正；这里借用方法，按小型桌面面板确认的密度落地，不直接套用官网的大字号。

- 同级元素保持同字号、行高、字重和间距；用组内较紧、组间较松的节奏建立关系。
- 字体角色由 `--text-body`、`--text-heading`、`--text-caption` 定义，分别为 12/18px、13/20px、11/16px；强调统一 600 字重。
- 公共内边距 8px，表单行距 6px，组件间距 8px，区块间距 12px。组件内部需要光学校正时明确局部用途，不改变整页密度。
- 页头、滚动内容和页脚使用相同的对称原生细滚动槽；左右实际留白需相等。受限宽度的工作区居中，其页脚操作与内容对齐。
- 文本输入框和选择器聚焦时使用共享的浅蓝色边缘及贴边柔光，不保留分离的粗蓝色 outline；按钮、链接等继续保留明确的键盘焦点标识。

## 共享组件

- `panel/style.css`：所有主题变量、环境背景、页面、表单、按钮、状态、目录及自适应布局的唯一来源。
- `panel/js/nav.js`：唯一功能清单，以及顶栏、主题、搜索、入口行和路由组件。
- 首页调用 `YunLiUI.mountCatalog`，入口行与分组从同一份数据生成；搜索匹配名称、说明和分组。
- 不固定导航项数量。新增工具在功能清单添加记录并接入对应页面；路由查找清单与实际页面，不维护第二份功能 ID 列表。
- `export-channel` 模板与对应样式：四色、工艺复用同一组件。参数、画板选择和工艺状态独立保留。
- `panel/font.css`：只定义字体校对、预览与局部布局，不复制主题、导航、按钮和输入框。
- 字体视图由 `build.ps1` 从参考标记生成后并入主 `index.html`，通过 `#fonts` 切换；不使用独立页面或 iframe。
- `panel/js/font-loader.js` 在首次进入时加载 OCR 资源；模块只初始化一次，返回后保留校对状态。`font/index.html` 仅兼容跳转到主视图。
- `panel/js/tool-bridge.js` 为所有视图维护唯一的请求编号与响应处理器；字体模块复用该传输层，不覆盖 `__zixingDeliver`。资源地址按脚本所在目录解析。
- 字体样式全部限定在 `.font-page` 或专属弹层内，不影响其他工具。不要直接改 `dist` 或参考插件实现 YunLi 的样式。

## 宿主尺寸与布局

以 `shell/src/main.c` 的实际声明为准：默认 348×648，最小 272×400。独立核心的 360×560 仅是另一项测试尺寸。宿主缩放后的实际 CSS 客户区仍需在 Illustrator 内验证。

采用桌面工具的自适应重排：保留参数值，根据页面任务调整分区与内部换行，不把窄面板一律变成纵向长表单；标记页必须保持左右分区。

- 全局：约 48px 的胶囊顶栏、滚动内容区、固定操作栏。
- 首页：标题由顶栏承担，连接和文档合并一行；只展示已开放工具，按分组使用紧凑多列入口。工具说明放在悬停提示中，仍参与搜索。未开放项目保留在清单中，不生成入口。
- 标记：272px 起始终保持左侧参数/标记类型、右侧附加信息。不在窄窗口改成上下卡片或隐藏其中一组。
- 每个分区内部按一行一个参数、一个选项排列，行内标签对齐。数值框与位置选择器共用宽度：52px，320px 以下为 48px。参数旁不重复标注 mm，底部统一说明“单位：毫米”。
- 工作区最大宽 480px；大窗口不再拉长数值框。备注等文本输入可随分区伸缩。
- 专色较多时列表局部滚动，不让次要数据不断推高整个表单。
- 导出：600px 以下四色、工艺上下排列，600px 起左右并排；两个通道共用模板，不复制页面。路径、浏览、日志置于同一行。
- 输出参数直接显示，按可用空间换行；抗锯齿选择器宽 92px，PPI 选择器宽 60px。卡片随内容自然增高，不填满空白窗口。
- 两个通道的抗锯齿默认“优化文字”；导出请求固定开启 LZW，界面不提供 LZW 或全选复选框，画板逐项勾选。
- 未勾选画板时收起其不可用的工艺选择器；勾选后原位显示。长画板名省略并提供完整名称提示。
- 每个画板行保留原脚本的 40×40 缩略图入口；两个通道共用同一缩略图请求，只加载可见画板，并可刷新。
- 点击缩略图打开共用查看器：默认适合窗口，支持原尺寸滚动、关闭按钮和 Escape。查看图片不改变勾选、工艺或输出参数。
- 原脚本的大图最长边约 600px；这里查看的是画板内容，不将预览冒充为分色或导出 TIFF 的校样。缩略图加载失败保留重试入口，不阻止导出。
- 取图由宿主临时 PNG 与核心传图组成，页面只接收图像数据；核心生成临时路径，宿主在成功/失败后恢复原活动画板。
- 首页连接行的「检查更新」读取仓库 `update.json`，按 jsDelivr、gh-proxy 等镜像依次回退；下载后校验 SHA-256，退出 Illustrator 时由后台脚本替换 `.aip` 并重新打开。
- PDF 转曲不读取当前文档，也不经过 Illustrator。页面只有一个文件浏览框，接受 .pdf 和带 PDF 层的 .ai；结果写在原文件旁边并沿用原扩展名。旧版非 PDF 兼容的 .ai 明确报错，不做猜测转换。有 Illustrator 私有数据时先去掉，预览里的活字再用嵌入的 Ghostscript 按字形转曲；没有嵌入字形时失败，不用替换字体。
- 输入框与选择器统一高 28px，主要操作高 32px。限制数值控件宽度，不使用整行伸缩，不通过改字号或整体缩放换取空间。
- 不禁用系统浏览器缩放；125%/150% 的可用空间按更窄的 CSS 视口重新适配。

## 验证门禁

- 必测 272×400、348×648、360×560、460×640、500×700、640×400、640×520、1280×800，覆盖浅深主题、未连接、模拟文档。
- 必须断言标记左右分区、导出窄窗上下/宽窗左右，以及数值框宽度和控件高度；不能仅以没有溢出作为合格依据。
- 必须量页头/内容的左右实际留白、操作栏对齐、同级文字的字号/行高/字重。滚动条预留空间也计入视觉边界。
- 窗口不足时允许内容纵向滚动，不得横向溢出或遮住操作栏。未连接/空画板时卡片不能被固定高度撑大。
- 启用等分线、修改附加信息和输出参数，逐项选择长名称画板，确认工艺选择器均可操作。
- 跨尺寸改变时，勾选、数字、工艺和导出路径保持；目录支持键盘。
- 字体与其他工具互切时 URL 只改变 hash，顶栏不重建、表单与校对状态不丢失；混合运行后标记、导出和图片预览仍可响应。
- `node tools/uitest/font-layout-test.cjs` 检查单页集成、控件 ID 和共享桥；`node tools/uitest/shared-bridge-test.cjs` 检查并发请求、进度和错误路由。
- 本地模拟预览 `index.html?frame-audit=1#fonts` 可记录字体视图从显示到脚本就绪的连续帧，检查页签与操作栏是否位移。
- `node tools/uitest/preview-host-test.cjs` 验证画板编号、文档切换、取图尺寸和活动画板恢复；真实 Illustrator 取图仍需实机验证。
- 首页搜索需覆盖匹配、清空和空结果状态。
- `python tools/uitest/serve.py dist/payload/assets/web 8736 tools/uitest/ui-preview.js` 启动模拟预览。
- 构建后 `node tools/uitest/design-audit.cjs` 为回归入口；旧截图探针含早期导航选择器，以该脚本为准。
- 模拟桥只能证明 UI 行为，不证明 OCR 质量或 Illustrator 的真实文档操作。
- 面板在插件启动时创建，按上次的显示状态恢复停靠位置与图标；收起时的图标使用内嵌 SVG 资源。快捷键 **Ctrl+Alt+Shift+Y** 仅在 Illustrator 为前台窗口时生效。
